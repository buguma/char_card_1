# 弹窗响应式与安卓全屏迭代

## 实现范围

- 安卓容器：隐藏状态栏和导航栏、透明系统栏、允许内容绘制至屏幕缺口区域；恢复应用、窗口重新获得焦点、切换方向和关闭键盘后恢复沉浸显示。
- Capacitor：关闭 SystemBars 的默认留白处理，避免 WebView 父容器再次为摄像头区域留整条空白；键盘单独避让。页面启用 `viewport-fit=cover`。
- 主游戏：通过 `module/game-dialogs.js` 和 `module/game-styles-dialogs.css` 的明确弹窗名单，分离标题、内容、操作区；移动原节点而非复制，保留原 ID、事件和业务入口。字体/按钮不再随着横屏总宽度无界放大；长内容滚动，复杂列表自适应分栏。
- 风格：保留古风纸纹、墨框、现有花纹按钮素材；减少装饰占用空间。扁平主题保留深色卡片和强调色，修复旧行内颜色导致的对比度问题。
- API 配置：`ui/settings-dialogs.css` 与 `.cfg-scroll-body`，常驻标题和取消/保存；窄屏表单、低高度横屏双列。提示词和相关编辑器限高并保持操作可达。
- 开局及小游戏：`secondary-pages-responsive.css` 按页面标记隔离规则，覆盖角色创建、选档、农场、炼丹、地图、战斗、21 点相关弹层/操作。旧 ST 入口仅补 viewport 配置，不宣称完成其全部 UI 重做。
- 打包映射：新增根 CSS 已纳入显式冻结和复制名单；module/ui 内新增文件按原递归规则进入 APK，保留精确字节核验。

## 可重复的验证入口

在项目根目录运行：

```powershell
node --test tests/scene3d/modal-layout.unit.mjs tests/scene3d/orientation.unit.mjs tests/scene3d/apk-unit.mjs tests/scene3d/native-immersive-unit.mjs
node tests/scene3d/dialog-responsive.browser.mjs .scene3d-work/dialog-review
node tests/scene3d/settings-dialogs.browser.mjs .scene3d-work/settings-review
node tests/scene3d/secondary-dialogs.browser.mjs
```

浏览器脚本使用独立测试浏览器上下文和合成存档，禁止外部 API 请求；截图及 JSON 证据写入 `.scene3d-work`，不使用真实玩家存档或密钥。测试用本地静态服务器会随脚本退出关闭。

- 原生全屏静态契约 4 项、方向切换 5 项、旧弹窗定位 5 项、APK 映射及防篡改 11 项通过；Java 与 Android 资源任务编译通过。
- 主游戏基础交互矩阵：`.scene3d-work/dialog-interactions-renderer/results.json`，136/136 通过。包含真实 3D renderer ready/frame/canvas 证据，不只验证偏好开关；包含操作栏点击命中、滚动后位置、背包关闭、技能分类、设置页签及业务字段未被改动的检查。

- 使用多模态实际检视截图后，修复了旧 transform 特异性导致的半屏偏移、古风技能筛选白字、扁平交易黑字/白底残留、存档厚边框及小字号、农场事件缩放图标的横向溢出等问题。

## 真机验收边界

本次环境 `adb devices` 没有连接的安卓设备。Java/资源编译和浏览器设备尺寸模拟不等于安卓真机验收；请在安装新包后检查：

1. 冷启动、后台返回、文件选择/系统弹窗返回后，时间/电量/网络状态栏及导航栏保持隐藏。
2. 古风/扁平 UI、2D/3D 场景下，游戏设置切换横竖屏，画面延展至刘海/挖孔周围，关闭和保存按钮不被缺口遮挡。
3. 手势导航与三键导航分别测试；从屏幕边缘主动滑出系统栏时短暂显示属于 Android 规定的系统操作，不应禁用退出手势。
4. 输入法打开/收起后能编辑并保存 API 配置、提示词、自由输入；窗口不会残留键盘高度空白。
5. 长背包、技能、历史、交易列表滚动到底，详情打开/返回及底部操作正常。
6. 农场/炼丹/战斗/地图打开和关闭，回到原游戏场景，业务状态不丢失。

物理摄像头区域自身不能显示像素。API 28–29 使用平台支持的 SHORT_EDGES 缺口模式；API 30+ 使用 ALWAYS。个别设备厂商的“应用全屏显示/隐藏刘海”设置仍可能覆盖应用窗口偏好。

候选构建遵循现有隔离 runRecord 流程，不覆盖旧 APK 或源 `apk/www`。构建命令见 `开发文档/3D整合/安卓沉浸与响应式候选构建.md`。Debug 候选包的内容/签名核验不代表正式签名、真机或存档升级兼容认证；安装前先导出存档，若签名不一致请勿直接卸载旧版以免丢失本地数据。
