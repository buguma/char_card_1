## 从新run构建候选

先确保生产源、构建scripts、依赖锁停止并行编辑。每次构建使用唯一runId/buildId；失败输出保留，禁止复用已存在的stage/资源目录或覆盖不可变release。

从工程根运行，下面用`<新版本>`占位，必须替换为从未使用的值；runRecord、resourceRoot、releaseDir同时对应同一个新目录。

```powershell
node scene3d/scripts/run-record.mjs --runRecord='E:\JJBurst\git\.scene3d-work\<新版本>\run.json' --runId=<新版本> --buildId=<新版本> --projectRoot='E:\JJBurst\git' --sourceRoot='E:\JJBurst\git\.scene3d-work\baseline-original\pro' --sourceManifest='E:\JJBurst\git\开发文档\3D整合\P0-资产清单.json' --resourceRoot='E:\JJBurst\git\.scene3d-work\<新版本>\resources' --releaseDir='E:\JJBurst\git\.scene3d-work\<新版本>\release' --publishRoot='E:\JJBurst\git\assets\sect3d'
node scene3d/scripts/import-assets.mjs --runRecord='E:\JJBurst\git\.scene3d-work\<新版本>\run.json'
node scene3d/scripts/build.mjs --runRecord='E:\JJBurst\git\.scene3d-work\<新版本>\run.json'
node scene3d/scripts/publish-assets.mjs --runRecord='E:\JJBurst\git\.scene3d-work\<新版本>\run.json'
node scene3d/scripts/verify-web.mjs --runRecord='E:\JJBurst\git\.scene3d-work\<新版本>\run.json'
```

每条命令必须检查退出码，失败不执行下一条。发布会切换正式current，须等待绑定旧版本的浏览器测试结束。只改宿主并不自动改变renderer buildId，最终候选仍需记录完整host字节。

1. 通过原游戏导出多代存档，在独立测试profile实际导入核对；不覆盖唯一备份。用户真实内容不进入测试报告/Git。

5. 模型文件hash不符、资源跨版、未知APK assets等错误不能通过跳过校验处理。
