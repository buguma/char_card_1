# 3D NPC 聚焦、水墨交互与悬浮地名

## 行为

- 3D 场景中，无论古风还是扁平 UI，点击可见 NPC 后，在约 420ms 内恢复该房间的初始视角，并平移、缩放到 NPC 中心。开启系统减少动态效果时直接完成。
- 用 NPC 实际世界坐标与相机投影计算缩放，目标高度为场景视窗的 29%，不依赖房间的初始缩放。窗口尺寸变化后重新计算。
- 复用 2D 古风 `npc-selection-*` 样式及 `assets/image/static/框选2.png`、`背景.png`；提供送礼、切磋、互动，继续调用原游戏业务函数。
- 人物介绍独立测量、优先扩宽，必要时微调字号，最多三行；不插入硬换行，不显示滚动条。使用均衡换行避免末行仅剩一两个字，保留原水墨背景。现有全部人物说明均完整显示。
- 选中人物使用金色（`#dba23c`）透明边缘轮廓，约 2 CSS 像素；逐帧跟随立绘透明像素，不描绘矩形卡片，不更改透明命中或深度遮挡。低画质与均衡画质均支持。
- 交互选框打开时锁定镜头操作，但人物动画继续播放。点击外部或 Escape 关闭，立即取消轮廓，并用约 420ms 平滑恢复该子场景初始位置、目标点和缩放，而非点击前手动旋转后的视角。窗口缩放不会破坏归位；切换场景、业务弹窗、隐藏页面及新选择会安全取消旧动画。菜单自身的 `scene-menu` 锁允许先预约归位，等完整状态解锁后再开始。
- 资源失败时保留同一 NPC 的文字入口；没有世界模型可供聚焦时，显示可操作的最小尺寸水墨菜单，不伪造角色模型。
- 天山派主场景显示 11 个地点名称，仅隐藏厢房文字，保留模型。山门锚定大门屋顶 `(0,13.054235,13.1)`，后山锚定东侧亭子顶端 `(19.8,10.08,-15.8)`，均由实际 GLB 顶点验证并跟随模型变换，不使用楼梯、吊桥入口或山体中心。白字黑边，无边框、底板，不拦截鼠标/触摸；正常保留视锥裁剪，不把离屏标签硬贴到边缘。主场景在日期/体力栏下方保留独立 3D 画面区域。

## 交互故障处理

已在完整导航流程中复现原始问题：从主场景进入后山，雨烛清晰可见但原生鼠标点击完全无效。翻页加载时桥接层传入 `interactive:false`，翻页结束却只调用镜头层的 `setInteractionEnabled(true)`，NPC 控制器保存的交互快照仍为 false。调试断点证实点击在输入门禁处被拒绝，尚未进入透明像素或遮挡判断；只修正这一个快照标志，同一点的真实点击即可成功。

修复方式是翻页结束后通过既有受保护的 apply 路径强制重发完整状态，统一恢复镜头、运行时快照及 NPC 控制器的交互状态，不放宽透明像素命中或遮挡检查。另修复一个独立风险：原 2D 关闭函数能够隐藏共享弹窗，但桥接层仍保留 `scene-menu` 锁，导致后续 3D 点击被拒绝。

本次 NPC 不再使用共享 `#npc-info-popup`，而使用桥接层独立管理的水墨选框，避免旧弹窗的文档点击关闭器干扰。同时补上弹窗隐藏/移除后的交互锁清理、页面不可见时关闭菜单，以及 NPC 菜单不暂停渲染的处理。外部弹窗在聚焦途中打开时，立即取消尚未完成的聚焦，避免关闭弹窗后自动弹回旧 NPC 菜单。

扁平模式会通过 `applyUIStyle` 禁用整份 `game-styles-theme.css`，因此不能只复用类名。3D 主机样式中保留了作用域限定的完整水墨布局、原图片与文字样式，使扁平模式也有实际可见、可点击的选框；2D 样式不受影响。古风通用 `.scene3d-menu` 还会施加 26px 边框及纸纹；3D 选框的坐标容器显式清除这些属性，避免水墨圈偏移 26px 和整屏额外底纹。

## 文件职责

- `module/scene3d-bridge.js`：业务校验、菜单生命周期、原有动作分派。
- `module/scene3d-host.css`：水墨菜单在 3D 视窗中的自适应排版。
- `scene3d/src/npc-focus.js`：正交相机聚焦计算。
- `scene3d/src/npcs.js`、`scene3d/src/npc-outline.js`：NPC 世界几何、客户端投影锚点、逐帧透明轮廓选中效果。
- `scene3d/src/runtime.js`：聚焦与取消归位动画、状态取消、位置更新。
- `scene3d/src/location-labels.js`、`scene3d/src/scene3d.css`：主场景模型地名。
