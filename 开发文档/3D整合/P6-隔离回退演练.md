## 真实浏览器覆盖

使用新 BrowserContext、合成存档、固定业务时间与 RNG seed；WebGL/renderer/GLB 均实际运行，没有替换为假 renderer。请求仅允许 owned loopback、data/blob 或已有本地合成静态替代；真实 API 未访问。mock SSE 通过原 performAction、pipeline/parser 和业务提交路径运行。

- B 会话先加载 main；CLI 回退 A 后，该旧会话进入此前未访问的 library，实际新增 GLB 请求仍指向 B，未重新取 pointer 或混入 A；真实原返回按钮可返回 main。
- 新上下文读取 A；再次激活后新上下文读取 B。JS/GLB 请求限定在各自选定版本目录。
- A、B 各执行完整 2D 与 3D 对照轨迹：main→library→mock SSE 学习→原返回→真实导出/导入。两版各自 2D==3D，A==B，完整 businessProjection（含 RNG）、SSE prompt/partial/commit、导出 payload 与运行 `apiService.getConfig()` 以及 localStorage 原始/解析 fake API 配置均零差异；切换前后亦分别核对配置保留。跨上下文只规范化 mock channel endpoint，其余配置保留。
- main/library 分别关闭 3D，完整业务快照和 RNG 不变；原 CSS 背景实际加载且 naturalWidth/naturalHeight 为正，原地图/返回/学习控件可见。已人工复核藏经阁 3D 与关闭后的原图/人物/控件截图。
- 保留切换前合成导出以及回退后真实学习所得第二代合成导出；执行原 importSave/FileReader/解析/恢复及再次导出。导出只替换最终 OS 下载传输，业务导出代码仍实际运行。
- 所有会话、browser、server 均经 finally 关闭；成功运行 job `pwsh-89` 已收集，退出 0。

使用现有 `enterFromBuildingMenu` 时，测试程序打开真实宿主菜单，再点击其原旅行按钮；这验证菜单/旅行业务路径，不宣称本轮覆盖画布建筑射线拾取。
