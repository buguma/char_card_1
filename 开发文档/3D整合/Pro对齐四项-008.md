# Pro对齐四项：008工作记录

## 用户要求（四项）

1. 3D场景设置并入「游戏设置」弹窗作为一个选项卡，提供与Pro对齐的可配置项（选项/默认值/效果对齐Pro），恰好11项：渲染分辨率、抗锯齿MSAA、日月光影、云海与远山薄雾、丁达尔光束、泛光强度、饱和度、对比度、中间调、暖调、暗角。
2. 主场景/子场景相互切换时不再先显示原2D画面再跳变3D，加入Pro同款翻页效果掩盖加载。
3. 每个场景的互动选项按钮改为绑定到3D自带的、悬浮在具体要素上的按钮；按钮样式保持现有古风/扁平UI风格下的按钮式样。
4. 主场景点击子场景时加边缘金色描边效果；同时选中子场景弹出的弹窗式样保持与原古风/扁平UI风格弹窗一致。
